# Logicc vertical slice — manual smoke (credential-safe)

Use only after automated fake-Logicc tests pass. Keep the app on localhost.

## Preconditions (boolean checks only)

```bash
# Confirm ignore + untracked — do not print key material
git check-ignore -v .env.local
git status --short
git ls-files --error-unmatch .env.local

# Boolean-only presence (no length/prefix/suffix/hash)
node -e "const fs=require('fs'); const t=fs.readFileSync('.env.local','utf8'); const ok=/^\s*LOGICC_API_KEY\s*=\s*\S+/m.test(t); const bad=/^\s*NEXT_PUBLIC_.*LOGICC/m.test(t); console.log(ok?'LOGICC_API_KEY:configured':'LOGICC_API_KEY:missing'); console.log(bad?'NEXT_PUBLIC_LOGICC:present':'NEXT_PUBLIC_LOGICC:absent');"
```

Configure non-secret settings in `.env.local` (never commit):

```bash
AGENT_PROVIDER=logicc
LOGICC_INTERNAL_MODE=true
LOGICC_ALLOWED_MODELS=<admin-approved-ids>
LOGICC_DEFAULT_MODEL=<must-be-in-allowlist-and-enabled>
```

Restart Next.js after editing `.env.local`. Bind to localhost only.

## Smoke checklist

Report only pass/fail — never paste credentials, headers, or raw network bodies.

1. Server credential readiness (health shows Ready, not the key)
2. Model discovery returns approved models only
3. Select an allowed model in the workspace UI
4. Text streams
5. Model requests a harmless tool → approval required
6. Tool executes exactly once
7. Safe result returns → final response completes
8. Cancellation works
9. Anthropic BYOK field is hidden in Logicc mode
10. Browser requests do not include `x-coderxp-byok-key`
